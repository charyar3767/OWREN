# Söz Ýatlatma (Flutter)

Iňlis-Türkmen sözlerini wagtly-wagtynda sesli bildiriş (notification) bilen ýatlatýan programma.

## GitHub-da APK almak
1. GitHub-da täze repo dörediň, şu faýllary ýükläň (`lib/`, `tools/`, `.github/`, `pubspec.yaml`).
2. **Actions** bölümine giriň → "Build APK" işleýär (ýa-da "Run workflow" basyň).
3. Işläp bolanda **Artifacts** → `soz-yatlatma-apk` → `app-release.apk` ýükläp alyň.

## Ulanyş
Çep menu → **Sazlamalar**:
- **Wagtlar**: ýatlatmany açyp/ýapmak, islendik sagat:minut goşmak, tertibi saýlamak, test.
- **Sözler**: täze söz/sözlem goşmak, **köp söz bir gezekde goşmak** (`Apple = Alma`), 🔊 iňlisçe aýdylyşy, ✅ "öwrendim" bellemek (öwrenilen sözler ýatlatmalardan aýrylýar), öçürmek. Başda 50 söz bar.

## Bildirişdäki düwme
Bildiriş gelende **Bilýärin** düwmesine bassaňyz, şol söz awtomatik "öwrenilen" bellenýär we indi ýatlatmalara gelmeýär (programmany açmak hökman däl).
